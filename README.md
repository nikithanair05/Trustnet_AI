# TrustNet AI 🚨
### AI-Powered Fake Profile & Scam Detection Platform

TrustNet AI is an advanced cybersecurity investigation platform designed to detect fake social media profiles and suspicious online activities using Machine Learning, NLP, Vector Search, and Retrieval-Augmented Generation (RAG).

The system analyzes profile behavior, profile bios, engagement metrics, and semantic scam patterns to identify potentially fraudulent or scam-related accounts.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/nikithanair05/Trustnet_AI.git
```

Move into project directory:

```bash
cd Trustnet_AI
```

Create virtual environment:

```bash
python -m venv venv
```

Activate virtual environment:

### Windows
```bash
venv\Scripts\activate
```

### Mac/Linux
```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 🚀 Run the Application

```bash
streamlit run app.py
```

The application will start locally at:

```text
http://localhost:8501
```

# 🔍 How TrustNet AI Works

1. User enters profile information
2. ML model predicts fake/genuine behavior
3. NLP embedding model converts bio into vectors
4. ChromaDB retrieves similar scam patterns
5. RAG pipeline generates investigation report
6. Results are visualized in the cybersecurity dashboard

---

# 📊 Core Functionalities

## 🔹 Fake Profile Detection
Detects suspicious account behavior using trained ML models.

## 🔹 Semantic Scam Retrieval
Finds similar scam-related profiles using vector embeddings.

## 🔹 AI Investigation Report
Generates contextual explanations for prediction outcomes.

## 🔹 Threat Intelligence Dashboard
Displays cybersecurity insights and threat monitoring interface.
